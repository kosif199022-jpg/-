# ALTAREEQ / الطريق

Clean-room financial, accounting, audit, assurance, knowledge and AI operating system for Saudi-market professional workflows.

## Non-negotiable architecture

- Deterministic money and accounting authority. AI never posts, approves or creates binding financial values.
- PostgreSQL is the relational system of record. Object/search/vector stores are derived or binary stores only.
- Multi-tenant identity, RBAC, RLS and separation of duties are application/database constraints.
- Audit is a persisted eight-stage lifecycle: acceptance → data validation → planning/risk → PBC/evidence → fieldwork → findings/conclusions → adjustments/review → completion/reporting.
- Professional citations must resolve to real persisted source versions/blocks. Synthetic references are test-only.
- Legacy repositories are discovery evidence only; production code cannot import their runtime business logic.
- Every preserved capability is tracked by the machine contract with risk, authority, parity state, acceptance criteria, test policy, dependencies and performance envelope.

## Honest status

This branch is a production-oriented foundation slice, not a claim that all legacy capabilities are already implemented. Unfinished capabilities remain `not_started` or `in_progress`; parity requires automated evidence.
